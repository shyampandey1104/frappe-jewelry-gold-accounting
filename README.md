# 💍 Frappe Jewelry, Bullion & Gold Karat Accounting Engine

[![Python 3.9+](https://img.shields.io/badge/python-3.9+-blue.svg)](https://www.python.org/downloads/)
[![ERPNext](https://img.shields.io/badge/Frappe-Jewelry-blue.svg)](https://frappeframework.com)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A specialized **Jewelry & Precious Metal Bullion Accounting Module** for **Frappe Framework & ERPNext**. Features MCX daily metal rates (24K, 22K 916 Hallmark, 18K), net weight separation (gross minus stones), melting/filing wastage %, making charge structures, and statutory 3% Gold GST billing.

---

## ⚡ Highlights
- 🏅 **Karat Purity Calculator**: 24K, 22K, 18K, 14K automatic rate prorating.
- ⚖️ **Weight Separation**: Deducts precious/semi-precious stone weights from gross ornament weight.
- 🔨 **Making Charges & Wastage**: Per-gram or percentage wastage calculation.
- 🧾 **Statutory 3% GST**: 1.5% CGST + 1.5% SGST compliance.
- 🧪 **Pytest Coverage**: Unit tests included.
